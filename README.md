# I ❤️ ME 定制贴图生成器

一个面向手机使用的静态网页贴图编辑工具。用户可以围绕「I + 符号 + 自定义文字」制作个性化图片，添加照片、纹理和贴纸，并导出作品。项目同时提供普通浏览器页面和适配小红书小工具环境的构建脚本。

## 项目解决什么问题

制作个性化表达图片通常需要在多个修图工具中完成排版、裁切和装饰。本项目把文字、符号照片填充、贴纸和背景编辑集中在一个页面中，让用户在编辑时持续看到画布效果，降低制作定制贴图的操作成本。

本项目使用预设排版和本地素材进行图片合成，当前没有接入 AI 生图或大模型服务。

## 主要功能

- **文字编辑**：默认文字为 `ME`，支持修改文字、间距、大小、颜色和纹理。支持英文字母、数字、空格以及代码中允许的英文和中文标点，最多 7 个字符；不支持汉字和表情。提交汉字时提示「无法输入中文」。
- **符号编辑**：支持爱心、星星、禁止符号和爪印，默认红色；可调整颜色、纹理，或上传照片填充符号，并拖动、缩放照片。
- **贴纸编辑**：提供推荐、Y2K、韩系、ins风和像素风分类，支持导入自己的图片，以及移动、缩放、旋转、水平翻转、复制和删除贴纸。选中后可在画布内任意位置单指拖动、双指缩放；轻点贴纸外取消选中。超出画布的部分会被裁切。
- **画布编辑**：支持 `1:1`、`3:4`、`9:16` 比例、背景颜色、背景照片、照片拖动缩放、纹理填充和背景显示开关。上传的图片可更换或清除。
- **实时预览**：画布预览与编辑区域分开，编辑内容在区域内部滚动；支持撤销、重做和清空。
- **作品导出**：普通浏览器中下载 PNG 图片；在具备 `window.xhs.miniTool` 接口的小红书环境中，调用保存到相册和发布笔记接口。

## 安装与本地运行

### 环境要求

- 日常使用：现代浏览器，以及用于启动静态服务器的 Python 3。
- 重新构建小红书版本：Node.js 18 或更新版本、Python 3，以及 Pillow、fontTools、Brotli。

项目没有 `package.json`，无需执行 `npm install`。从 GitHub 下载 ZIP 并解压，或克隆仓库后，在项目根目录执行：

```bash
python3 -m http.server 8788 --bind 127.0.0.1
```

浏览器打开：

```text
http://127.0.0.1:8788/figma-doing-interactive.html
```

请保留页面、JavaScript、`assets/` 和页面引用的 `素材包/` 字体资源的相对目录关系。建议通过 HTTP 访问，以减少浏览器对本地文件的限制。

### 重新构建小红书小工具版本

如需处理更新后的原始素材，先安装 Python 构建依赖：

```bash
python3 -m pip install Pillow fonttools brotli
```

在项目根目录按顺序执行：

```bash
python3 prepare-sticker-catalog.py
node build-minitool.mjs
python3 prepare-minitool-assets.py
node compact-minitool.mjs
```

输出目录为 `minitool-dist/`，入口为 `index.html`。素材处理会裁去透明边缘并生成 WebP；精简脚本会将部分小图片嵌入脚本，以控制发布文件数量。以上步骤需要按顺序执行。

在 macOS 或 Linux 上可用以下命令打包：

```bash
cd minitool-dist
zip -r ../i-design-minitool.zip . -x '*.DS_Store' '__MACOSX/*'
cd ..
```

上传包应直接包含根目录的 `index.html`，不要再套一层 `minitool-dist` 文件夹。上传前确认平台统计的文件数不超过 200，并在平台模拟器及 Android、iOS 真机测试相册权限、发布流程和键盘交互。

## 使用方法

1. 打开页面，默认画布显示红色爱心和 `I / ME` 组合。
2. 在「文字」中输入英文或标点，调整大小、间距、颜色和纹理；中文输入法提交的英文字母也应按实际字符处理。
3. 在「符号」中选择符号，按需上传照片并在预览区域拖动或缩放。
4. 在「贴纸」中选择分类、添加贴纸，选中后使用控制按钮调整大小、角度或水平翻转。
5. 在「画布」中设置比例和背景；需要时上传照片、开启纹理或关闭背景显示。
6. 点击「导出」查看作品，选择保存图片；小红书小工具环境中还可进入发布笔记流程。点击「重新编辑」可返回修改。

普通浏览器中的「保存到相册」按钮实际触发 PNG 下载，是否进入系统相册由浏览器和设备决定。「发布笔记」需要小红书宿主接口，GitHub Pages 或本地浏览器不能独立提供此能力。进入发布流程不代表已经完成公开发布。

## 输入输出示例

| 场景 | 输入或操作 | 输出或反馈 |
| --- | --- | --- |
| 默认作品 | 打开页面 | 白色方形画布，黑色 `I`、红色爱心和黑色 `ME` |
| 自定义文字 | 输入 `ME` | 画布主文字更新为 `ME`，保留英文大小写 |
| 中文输入法 | 使用中文输入法提交 `Hello!` | 主文字显示 `Hello!` |
| 不支持的文字 | 提交 `你好` | 汉字被过滤，并提示「无法输入中文」 |
| 长文字 | 输入 `ABCDEFGH` | 最多保留前 7 个允许字符，即 `ABCDEFG` |
| 照片贴图 | 上传照片到爱心，添加贴纸，选择 `3:4` | 生成包含照片填充符号、文字和贴纸的竖向作品 |
| 浏览器导出 | 点击「导出」→「保存到相册」 | 下载文件 `i-love-me.png` |
| 小红书发布 | 在支持的小工具环境点击「发布笔记」 | 向宿主提交当前生成图片和下方预设文案 |

发布预设文案：

```text
标题：我的I❤️ME定制贴图
正文：用I❤️ME生成器一键生成的，快来试试吧😋
标签：#小工具#I❤️ME#生成器#diy
```

## 目录说明

| 路径 | 用途 |
| --- | --- |
| `figma-doing-interactive.html` | 普通浏览器版本入口及主要编辑逻辑 |
| `designer-color-picker.js` | 颜色选择器 |
| `minitool-export.js` | 小红书版本图片合成、保存及发布接口适配 |
| `sticker-catalog.js` | 生成的贴纸分类和排序目录 |
| `assets/` | 优化后的贴纸及编辑控制图标 |
| `素材包/` | 原始图片和字体素材 |
| `prepare-sticker-catalog.py` | 生成贴纸分类目录 |
| `build-minitool.mjs` | 构建小红书静态入口及脚本 |
| `prepare-minitool-assets.py` | 转换字体和贴纸资源 |
| `compact-minitool.mjs` | 精简发布目录文件数量 |
| `minitool-dist/` | 小红书版本构建输出，可作为静态站点目录托管 |
| `tests/` | 编辑、布局、素材、发布适配及包体检查脚本 |
